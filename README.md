## 📖 Sobre o projeto

O **Caminhos de Santiago** é um projeto académico desenvolvido com o objetivo de aplicar conhecimentos de desenvolvimento web na criação de uma plataforma relacionada com os percursos de peregrinação a Santiago de Compostela.

A aplicação foi pensada para reunir funcionalidades úteis para quem pretende conhecer os caminhos e organizar a sua experiência, combinando uma interface web com ferramentas de navegação e gestão de informação.

Para além da componente visual, o desenvolvimento permitiu trabalhar a organização do código, a interação com dados, a navegação entre páginas e a integração de funcionalidades como mapas e geolocalização.

## ✨ Funcionalidades

* **Exploração de percursos** — consulta de informação relacionada com os Caminhos de Santiago.
* **Mapa interativo** — visualização de localizações através de mapas.
* **Geolocalização** — utilização de funcionalidades de localização.
* **Planeamento** — organização da informação necessária para preparar o caminho.
* **Favoritos** — acesso rápido a conteúdos guardados.
* **Autenticação** — funcionalidades associadas à conta do utilizador.
* **Área de administração** — gestão da informação da plataforma.

## 🚀 Instalação e execução

Segue os passos abaixo para obter uma cópia do projeto e executá-lo localmente.

### 1. Pré-requisitos

Antes de começar, certifica-te de que tens instalado:

* [Node.js](https://nodejs.org/) — inclui o npm.
* [Git](https://git-scm.com/) — para clonar o repositório.
* [Visual Studio Code](https://code.visualstudio.com/) — recomendado para editar e executar o projeto.

### 2. Clonar o repositório

Abre um terminal e executa:

```bash
git clone https://github.com/JoaoPreto1/Projeto-Caminhos-Santiago.git
```

Entra na pasta criada:

```bash
cd Projeto-Caminhos-Santiago
```

### 3. Instalar as dependências

Na raiz do projeto, executa:

```bash
npm install
```

Este comando instala os pacotes definidos no `package.json` e prepara o ambiente de desenvolvimento.

### 4. Iniciar a aplicação

Depois de concluída a instalação, executa:

```bash
npm start
```

Se o comando estiver configurado no `package.json`, a aplicação será iniciada através do script definido no projeto.

**Nota:** se o projeto utilizar o JSON Server como serviço separado, este também terá de ser iniciado. Consulta os scripts do `package.json` e a configuração existente para confirmar se é necessário executar um segundo comando num terminal diferente.

### 5. Abrir no navegador

Segue o endereço apresentado no terminal após o arranque da aplicação.

Se o projeto for executado através do Live Server, abre o ficheiro `home.html` no Visual Studio Code e seleciona **Open with Live Server**.
